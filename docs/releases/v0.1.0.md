# ORIENTA MVP 1 · v0.1.0

Primer release del MVP, promovido desde `dev` mediante una rama `release/v0.1.0` y un PR hacia `main`.

## Funcionalidades

- Inicio responsive con carrusel de las 23 instituciones, logos horizontales y cifras animadas que respetan movimiento reducido y modo ligero.
- Catálogo conectado a PostgreSQL: 414 ofertas, 170 carreras, 23 instituciones, 27 sedes y 8 distritos de Lima Norte.
- Búsqueda y filtros dependientes por tipo, institución, área, carrera, modalidad y distrito, con estado compartible en la URL.
- Fichas con duración, modalidad, ubicación, contexto editorial, documentos y fechas de consulta.
- Comparación de dos ofertas, con nombres de carreras, instituciones y sedes en lugar de etiquetas genéricas.
- Explicación con Gemini según prioridades declaradas, referencias verificadas estructuralmente y comparación básica disponible si la IA falla.
- Índice ML de coincidencias léxicas y clasificación editorial; no constituye un test vocacional ni predice compatibilidad o éxito.

## Operación

React + TypeScript, FastAPI + Python y PostgreSQL en InsForge. Sin login ni registro. Las credenciales permanecen fuera del repositorio y Gemini se utiliza desde el backend.

La instalación, variables de entorno, importación de datos y ejecución local se describen en el [README de esta versión](https://github.com/HuamaniAlexander/Orienta-Proyecto/blob/v0.1.0/README.md). Publicar este release no despliega la aplicación en un servicio de producción.

## Verificación

La promoción a `main` requiere CI correcto: lint, tipos y build del frontend; pruebas de navegador y accesibilidad; ruff, mypy y pruebas del backend; auditoría de importación e imagen Docker. La integración contra la base real es opt-in y no se activa en CI.

Los datos académicos conservan sus fuentes y fechas. Los costos o campos ausentes deben confirmarse con la institución. La validación de estructura y referencias de IA no garantiza cada interpretación.
